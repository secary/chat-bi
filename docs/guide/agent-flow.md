# ChatBI 运作流程（简图）

从用户提问到页面展示结果的抽象流程。界面说明见 [user-guide.md](user-guide.md)。

---

## 1. 整体：一问一答

```mermaid
flowchart LR
    A[用户输入问题] --> B[Agent 理解与编排]
    B --> C[调用技能查数 / 分析]
    C --> D[整理结果]
    D --> E[页面展示<br/>文字 · 图表 · KPI]
```

---

## 2. 单 Agent 模式（默认）

一个 Agent 反复「想 → 做 → 看结果」，直到能回答用户。

```mermaid
flowchart TB
    U[用户输入] --> AG[Agent]
    AG --> DEC{下一步?}
    DEC -->|需要查数或分析| SK[执行一项技能]
    SK --> OBS[得到数据摘要]
    OBS --> AG
    DEC -->|信息不够| ASK[向用户追问]
    ASK --> OUT[结束]
    DEC -->|可以作答| FIN[生成回答]
    FIN --> OUT[文字 / 图表 / KPI]
```

**三种决策（对用户而言）**

| 决策 | 含义 |
|------|------|
| 执行技能 | 去数据库或文件里取数、算指标、出图等 |
| 追问 | 问题不清楚，先问用户补全条件 |
| 完成 | 用已有结果组织成最终回答 |

---

## 3. 多专线模式（开启「多专线协作」）

先由 **协调者** 拆成几个子任务，再交给 **不同专线的 Agent** 分别处理，最后 **汇总** 成一条回答。

```mermaid
flowchart TB
    U[用户输入] --> M[协调者 Agent<br/>拆解子任务]
    M --> L1[专线 A<br/>如：问数]
    M --> L2[专线 B<br/>如：环比]
    M --> L3[专线 C<br/>如：图表]
    L1 --> R1[子结果]
    L2 --> R2[子结果]
    L3 --> R3[子结果]
    R1 --> S[汇总]
    R2 --> S
    R3 --> S
    S --> OUT[统一回答给用户]
```

每个专线 Agent 内部仍是：**想 → 执行技能 → 看结果 → 完成或追问**（与单 Agent 相同，只是擅长的任务不同）。

---

## 4. 两种模式怎么选

```mermaid
flowchart LR
    Q[用户提问] --> SW{多专线协作?}
    SW -->|关闭| ONE[一个 Agent 包办]
    SW -->|开启| MULTI[协调者 + 多个专线 Agent]
    ONE --> ANS[回答]
    MULTI --> ANS
```

| | 单 Agent | 多专线 |
|--|----------|--------|
| 适合 | 简单问数、单一步骤 | 既要查数又要环比、图表等多步组合 |
| 感受 | 一条线做完 | 分头做再合成一篇回答 |

---

## 5. 用户侧能看到什么

```mermaid
flowchart LR
    IN[输入框发送] --> WAIT[思考过程提示]
    WAIT --> RES[回答区]
    RES --> T[说明文字]
    RES --> C[图表]
    RES --> K[指标卡片]
```

过程中可随时 **中止**；需要登录时须先登录（开发环境可能默认免登录）。
