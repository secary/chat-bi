# 数据源配置

面向管理员，说明如何维护外部 MySQL 连接和默认问数来源。

## 页面用途

- 保存外部 MySQL 连接，供对话问数和 Skill 执行时使用。
- 勾选“设为默认数据源”后，未指定数据源的对话会优先使用该连接。
- 如果没有保存的默认数据源，系统会回退到环境变量里的默认连接。

## 字段说明

| 字段 | 说明 |
|------|------|
| 名称 | 页面展示和对话切换数据源时使用的可读名称。 |
| 主机 / 端口 | MySQL 服务地址和端口。 |
| 用户名 / 密码 | 建议使用只读账号，密码编辑时留空表示不修改。 |
| 数据库名 | 实际要连接的 schema。 |
| 默认数据源 | 同一时间只应有一个默认连接。 |

## 本地预置连接

- 本地开发可使用 CHATBI_DB_CONNECTION_<N>_* 变量预置多套连接。
- 启动 scripts/start_dev.sh 时会按名称 upsert 到 admin_db_connection。
- DEFAULT=true 的连接会成为默认数据源。

## 排查建议

- 保存失败先确认后端和 Vite 代理都在运行。
- 连接测试失败时检查主机、端口、账号权限和数据库名。
- 对外或生产数据源优先使用只读、脱敏账号。
