# LLM 配置

面向管理员，说明模型 Profile、API Key、测试连接和当前生效配置。

## 当前使用

- 页面顶部展示当前实际生效模型、API Base 和 API Key 是否已配置。
- 未保存 Profile 时，系统使用 .env.dev 或 .env 中的 LLM_MODEL、API_BASE、OPENAI_API_KEY。
- 激活某个已保存 Profile 后，Profile 会覆盖环境变量中的模型配置。
- 已保存模型中会展示“默认配置”，可随时切回并测试连接。

## 保存模型

- 选择模型名前缀，填写模型名、Base URL、API Key 和备注名后点击“测试并启用”。
- 测试通过才会保存并激活，避免不可用配置影响对话。
- 编辑已有模型时，API Key 留空会沿用原密钥。

## 常见问题

| 现象 | 优先检查 |
|------|----------|
| 读取配置失败 | 后端是否启动、管理表是否已初始化。 |
| 连接测试失败 | API Key、Base URL、模型名和服务商额度。 |
| 当前使用仍是默认配置 | 是否已经激活某个保存的 Profile。 |
