# ChatBI 普通用户手册

本文面向使用 ChatBI 提问、上传文件和查看分析结果的业务用户。这里不包含管理后台、系统部署、密钥、数据库或代码实现内容。

## 1. ChatBI 能帮你做什么

ChatBI 是银行场景的对话式数据分析工具。你可以用中文提出业务问题，系统会返回文字结论、指标卡片、图表、表格或分析看板。

常见能力：

- 查询指标：例如销售额、订单量、客户数等。
- 做排行、趋势和对比：例如按区域排行、按月份趋势、环比对比。
- 生成经营建议：基于已经查询到的数据给出建议。
- 解释指标口径：询问某个指标怎么计算。
- 上传 CSV 或 XLSX 文件：预览文件内容，生成指标提案，采纳后查看分析看板。
- 导出 PDF：将当前会话整理为报告。

## 2. 登录与界面

打开系统地址后，如果出现登录页，请使用管理员分配的账号和密码登录。

登录后主要使用左侧的“对话”入口。普通用户通常只需要关注三个区域：

| 区域 | 用途 |
|---|---|
| 会话列表 | 新建、切换或删除历史对话 |
| 消息区 | 查看提问、思考步骤、图表、指标卡片和分析结果 |
| 输入区 | 输入问题、上传附件、发送或中止当前生成 |

如果系统正在生成回答，发送按钮会变为“中止”。点击后会停止当前分析。

## 3. 怎么提问效果更好

尽量把指标、时间、范围或维度说清楚。

| 目标 | 推荐问法 |
|---|---|
| 查指标 | `2026 年 1-4 月各区域销售额排行` |
| 看趋势 | `2026 年每月销售额趋势` |
| 做对比 | `4 月相较于 3 月各区域销售额环比` |
| 要建议 | `基于 2026 年 1-4 月各区域销售额，给出经营建议` |
| 问口径 | `销售额是怎么计算的` |
| 上传分析 | 上传文件后输入 `分析这个文件，并给出可采纳的指标` |

如果只输入“给我建议”这类范围不清的问题，系统可能会先追问你要分析的指标、时间或业务范围。

## 4. 查看回答

助手消息可能包含以下内容：

| 内容 | 说明 |
|---|---|
| 思考步骤 | 展示系统分析过程，可折叠查看 |
| 文字结论 | 用自然语言总结结果，可能包含 Markdown 表格 |
| KPI 卡片 | 展示关键指标值 |
| 图表 | 展示排行、趋势、对比等分析结果 |
| 指标提案 | 上传文件后，系统建议可分析的指标 |
| 采纳看板 | 采纳指标后生成的图表、KPI 和数据表 |
| 错误提示 | 当前问题无法完成时的友好说明 |

图表和结论应结合使用。如果文字结论和图表看起来不一致，请优先联系管理员，并附上问题原文和会话时间。

## 5. 上传文件分析

上传支持 CSV 和 XLSX 文件。推荐流程：

1. 点击输入区的附件按钮并选择文件。
2. 发送分析问题，例如 `分析这个文件，给出关键指标提案`。
3. 查看系统生成的指标提案。
4. 回复 `采纳全部指标`，或指定要采纳的指标。
5. 查看采纳看板中的 KPI、图表和数据表。

上传前建议确认：

- 表头清晰，例如“月份”“区域”“销售额”。
- 同一列的数据类型尽量一致。
- 不上传未授权的敏感数据。

## 6. PDF 报告

在对话页可将当前会话导出为 PDF。报告内容来自当前会话中的问题、回答、图表和分析结果。

如果 PDF 中文显示异常，请联系管理员处理字体或部署环境问题。

## 7. 常见问题

| 问题 | 处理建议 |
|---|---|
| 登录失败 | 确认账号、密码是否正确，或联系管理员重置密码 |
| 回答说需要补充条件 | 重新提问时补充时间、指标、区域或对象 |
| 没有出现图表 | 问题可能偏解释类，或结果不适合出图；可以明确说“请用图表展示” |
| 上传文件解析失败 | 检查文件格式、表头、空行和异常字符 |
| 结果不是预期口径 | 询问指标口径，或联系管理员维护语义别名 |
| 生成时间太长 | 点击“中止”，缩小时间范围或减少分析目标后重试 |
